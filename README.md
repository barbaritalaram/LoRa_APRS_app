# LoRa_APRS_app

A cross-platform mobile application in Flutter to interact with LoRa APRS hardware, inspired by Meshtastic.

## 🚀 Objective

Enable communication between smartphones and LoRa APRS devices via Bluetooth (BT/BLE), providing a modern, secure, and efficient experience.

## ✨ Main Features

- Bidirectional communication with LoRa APRS nodes via Bluetooth Classic and BLE
- Real-time chat and local message persistence
- Support for plain text, AX.25, and AES-256 encrypted messages
- UI/UX inspired by Meshtastic
- Modular, extensible, and secure architecture
