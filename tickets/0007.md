# Ticket 0007: UI para el Escaneo de Dispositivos Bluetooth

**Estado:** Completado

## Descripción

Crear la interfaz de usuario que permita al usuario iniciar un escaneo de dispositivos Bluetooth, ver la lista de dispositivos encontrados y manejar los diferentes estados del proceso (escaneando, éxito, error, lista vacía).

## Requisitos

- [x] Crear una nueva página/vista para el escaneo de Bluetooth.
- [x] Añadir un botón para iniciar el proceso de escaneo.
- [x] Mostrar un indicador de carga mientras el escaneo está en progreso.
- [x] Mostrar la lista de dispositivos encontrados. Cada elemento de la lista debe mostrar el nombre y la dirección del dispositivo.
- [x] Mostrar un mensaje adecuado si no se encuentran dispositivos.
- [x] Manejar y mostrar los posibles errores que ocurran durante el escaneo.
- [x] Implementar un BLoC para manejar el estado de la UI de escaneo.
- [x] Integrar el `ScanForDevicesUseCase` con el BLoC.
