# Ticket 0006: Implementar el servicio de escaneo de Bluetooth

**Estado:** Completado

## Descripción

Implementar la funcionalidad de escaneo de dispositivos Bluetooth LE para descubrir los módulos LoRa APRS cercanos. Este servicio será la base para la conexión y comunicación con los dispositivos.

## Requisitos

- [x] Configurar los permisos de Bluetooth para Android (`AndroidManifest.xml`).
- [x] Configurar los permisos de Bluetooth para iOS (`Info.plist`).
- [x] Añadir las dependencias `flutter_blue` y `permission_handler`.
- [x] Implementar la lógica de escaneo en `RemoteDatasourceImpl`.
- [x] Filtrar los dispositivos para mostrar solo aquellos cuyo nombre contenga "LoRa" o "APRS".
- [x] Crear los casos de uso `ScanForDevicesUseCase`, `ConnectToDeviceUseCase` y `DisconnectFromDeviceUseCase`.
- [x] Registrar los nuevos componentes en el inyector de dependencias.
- [x] Implementar la lógica de conexión y desconexión en `RemoteDatasourceImpl`.
