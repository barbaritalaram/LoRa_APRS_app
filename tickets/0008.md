# Ticket 0008: Implementar Conexión a Dispositivo Bluetooth

**Estado:** Completado

## Descripción

Ampliar la funcionalidad de la pantalla de escaneo para permitir a los usuarios iniciar y finalizar una conexión con un dispositivo Bluetooth de la lista. La interfaz de usuario debe reflejar el estado actual de la conexión (desconectado, conectando, conectado, error).

## Requisitos

- [x] Crear un `DeviceConnectionBloc` para gestionar el estado de la conexión.
- [x] El BLoC debe manejar los estados: `ConnectionInitial`, `ConnectionInProgress`, `ConnectionSuccess`, `ConnectionFailure`.
- [x] Integrar `ConnectToDeviceUseCase` y `DisconnectFromDeviceUseCase` en el nuevo BLoC.
- [x] Modificar la UI de la lista de dispositivos para que cada elemento sea "tappable".
- [x] Al tocar un dispositivo, se debe iniciar el proceso de conexión.
- [x] Mostrar un indicador de carga o un cambio visual en el elemento de la lista mientras la conexión está en proceso.
- [x] Una vez conectado, mostrar un estado de "Conectado" y un botón para desconectar.
- [x] Manejar y mostrar los errores de conexión.
- [x] Registrar el nuevo BLoC en el inyector de dependencias.
