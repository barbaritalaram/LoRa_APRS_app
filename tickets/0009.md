# Ticket 0009: Implementar la Vista de Chat y la Comunicación de Mensajes

**Estado:** Completado

## Descripción

Crear una pantalla de chat que se muestre después de conectarse a un dispositivo. Esta pantalla permitirá al usuario enviar mensajes de texto al dispositivo conectado y ver los mensajes recibidos en tiempo real.

## Requisitos

- [x] Crear un `ChatBloc` para gestionar el estado de los mensajes (lista de mensajes, estado de envío).
- [x] Integrar `SendMessageUseCase` y `GetMessageStreamUseCase` (este último hay que crearlo) en el `ChatBloc`.
- [x] Al conectarse con éxito a un dispositivo, navegar automáticamente a una nueva `ChatPage`.
- [x] La `ChatPage` debe mostrar los mensajes enviados y recibidos.
- [x] Añadir un campo de texto y un botón de enviar para componer y mandar nuevos mensajes.
- [x] Actualizar el `IRemoteDatasource` y su implementación para manejar el envío y la recepción de datos a través de las características de Bluetooth.
- [x] Actualizar la UI para mostrar cuando un mensaje se está enviando.
- [x] Registrar el nuevo BLoC y el nuevo caso de uso en el inyector de dependencias.
